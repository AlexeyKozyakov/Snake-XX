## Snake XX
<img src="./app/src/main/res/drawable/app_icon.png" alt="Game logo" width="150" height="150">
Snake XX is the classic snake game for android with some additional mechanics written using Jetpack Compose.

## How to play
### Grow snake
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/eat_apples.png" alt="Eat apples" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>collect apples and bonuses and increase the snake length</li>
        <li>earn points for growing your snake and completing levels</li>
      </ul>
    </td>
  </tr>
</table>

### Pass levels
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/wall_block_0.png" alt="Wall" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>to pass the level reach the length displayed on top of the screen</li>
        <li>walls position, game speed and intelligence of the second snake changes with each level</li>
      </ul>
    </td>
  </tr>
</table>

### Collect coins
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/coin.png" alt="Coin" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>collect coins and diamonds on game field</li>
        <li>buy skins, upgrades and boosters for earned coins</li>
      </ul>
    </td>
  </tr>
</table>

### Avoid reduction
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/snake_yellow_xx.png" alt="Snake head xx" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>avoid walls, enemy snake, bad items and your tail</li>
        <li>this things reduce your size or finish game</li>
      </ul>
    </td>
  </tr>
</table>

## Apples and items

### Green apple
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/apple_green.png" alt="Green apple" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>increases snake length by one</li>
        <li>gives you one game point</li>
      </ul>
    </td>
  </tr>
</table>

### Red apple
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/apple_alt.png" alt="Red apple" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>does the same as green apple</li>
      </ul>
    </td>
  </tr>
</table>

### Omnivorousness egg
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/easter_egg.png" alt="Egg" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>activates omnivorousness mode where you can eat any items and grow</li>
        <li>the mode continues until the snake's head changes back to the normal one</li>
        <li>increases snake length by one</li>
      </ul>
    </td>
  </tr>
</table>

### Golden apple
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/apple_gold_64.png" alt="Golden apple" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>turn all bad items on the screen to apples</li>
        <li>increases snake length by one</li>
      </ul>
    </td>
  </tr>
</table>

### Stone
<table>
  <tr>
    <td>
      <img src="./app/src/main/res/drawable/oliebol_64.png" alt="Stone" width="100" height="100">
    </td>
    <td>
      <ul>
        <li>decreases snake length by one</li>
        <li>game will be finished if snake length became less than two</li>
      </ul>
    </td>
  </tr>
</table>

### Bomb
<table>
  <tr>

      <img src="./app/src/main/res/drawable/bomb.png" alt="Bomb" width="100" height="100">
    </td>
    <td>
