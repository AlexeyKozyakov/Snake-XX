Snake XX is a classic snake game on android with some additional mechanics written using Jetpack Compose. 
Pass different levels which differs by walls position, snake speed and required length to reach new level.
Collect coins and buy skins, boosters and upgrades in game shop.
The game has second ai snake, optional sound effects, background music and haptic feedback. Supported languages are english and russian.
